# INTRODUCTION
The W3CSS Paragraphs module provides a suite of content and layout Paragraph
bundles made with the W3.CSS front-end framework.

Combine the power of the w3.css front end framework with Drupal Paragraphs,
the powerful module to allow content creators to build
layouts and structured pages.

Using the w3.css Paragraphs Drupal module, you'll be able to create w3.css
features like Accordions, Carousels, Modals, Tabs, and Multi-column layouts.
You can also harness the power of Drupal referencing Text, Images, Blocks,
and even Views!
